  1. La connexion s'ouvre dans votre navigateur habituel (Chrome, Safari…) : Google refuse souvent la connexion dans un navigateur intégré.
  2. API Google Drive : cliquez sur « Activer ».
  3. Audience : « Publier l'application » (Production). À défaut, ajoutez votre adresse Gmail dans « Utilisateurs test » (l'autorisation expirera alors tous les 7 jours).

  5. Clients : type « Application de bureau », JSON enregistré sous credentials.json à la racine du projet.
  6. Si Google affiche « Google n'a pas validé cette application », cliquez sur « Continuer » : c'est normal pour une application personnelle.
